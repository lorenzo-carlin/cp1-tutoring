## ✨ What is this?

This repository collects the problem sets used during the **Computer Programming 1** tutoring sessions. It works like an interactive workbook: **no downloads, no setup** — just click a session and start reading the problems.

Every session includes:

- 📝 **Exercises** with problem statements, function prototypes, and input/output examples;
- 🔑 **Solutions** in C++, published **after** the tutoring class.

---

## 🧭 How it works

> **Try first, peek later.** Solutions are released after each class, so you have time to write your own code before checking the answers.

1. Open a session from the table below.
2. Pick an exercise and read the problem statement carefully.
3. Write your solution in C++, compile it, and test it with the provided examples.
4. Compare your approach with the official solution — and don't be afraid to experiment!
