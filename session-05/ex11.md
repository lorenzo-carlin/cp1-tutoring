# Exercise 11: Supermarket Inventory & Restock Cost Manager

### 📝 Problem Statement
Write a C++ program that manages the inventory for a retail store selling 8 distinct product items (indexed from `0` to `7`). The system uses two parallel 1D arrays of size 8:
- `int stock[8]`: stores the current stock quantity for each product.
- `double prices[8]`: stores the unit retail price for each product.

The program must:
1. Calculate the total monetary value of the current inventory ($\sum \text{stock}[i] \times \text{price}[i]$).
2. Identify low-stock products whose quantity is strictly below a safety threshold (e.g., 5 units).
3. Compute the total restock cost needed to replenish every low-stock item back up to a target capacity (e.g., 20 units).

Implement the following functions:
```c++
double calculateInventoryValue(const int stock[], const double prices[], int size);
double processRestock(const int stock[], const double prices[], int size, int threshold, int targetCapacity);
```

### 📥 Input / Output Example
```text
Enter stock quantity for 8 products:
15 3 22 1 0 12 4 18

Enter unit prices ($) for 8 products:
2.50 10.00 1.20 15.50 8.00 3.00 25.00 5.00

Enter safety stock threshold: 5
Enter target restock capacity: 20

=== INVENTORY REPORT ===
Total current inventory value: $335.4

Low Stock Items Alert (Stock < 5):
- Product 1: 3 in stock -> Needs 17 units (Cost: $170)
- Product 3: 1 in stock -> Needs 19 units (Cost: $294.5)
- Product 4: 0 in stock -> Needs 20 units (Cost: $160)
- Product 6: 4 in stock -> Needs 16 units (Cost: $400)

Total Budget Required for Restock: $1024.5
```
