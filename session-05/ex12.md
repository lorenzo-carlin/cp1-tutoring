# Exercise 12: Cellular Automaton Grid Colonization Simulator

### 📝 Problem Statement
Write a C++ program that simulates a cellular colonization process on a $10 \times 10$ grid. Each cell is either empty (`0`) or filled/colonized (`1`).

On each day, every filled cell (`1`) colonizes its orthogonal neighbors (up, down, left, right), turning them into filled cells (`1`) for the next day.

Implement the following modular functions:
- `bool isFullyColonized(const int grid[][10], int rows)`: returns `true` if all cells in the grid contain `1`, and `false` otherwise.
- `void simulateOneDay(int grid[][10], int rows)`: performs the state transition from day $D$ to day $D+1$.

The program continues the simulation day by day until the entire grid is colonized, outputting the total number of days required.
