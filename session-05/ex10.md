# Exercise 10: Smartwatch Fitness Tracker & Goal Streak Analyzer

### 📝 Problem Statement
Write a C++ program that simulates a smartwatch daily step-tracking system over a 10-day period. The program stores the daily step count in a 1D array of size 10, using 0-based indexing (from Day 0 to Day 9).

The user inputs the 10 daily step values and a daily step goal (e.g., 8000 steps). The program must compute and display:
1. The overall average daily step count.
2. The best day (identified by its 0-based index, e.g., Day 0, Day 1, etc.) with the highest step count.
3. The longest active streak (the maximum number of consecutive days where the step count met or exceeded the daily goal).

Implement the following modular functions:
```c++
double calculateAverageSteps(const int steps[], int size);
int findBestDayIndex(const int steps[], int size);
int countLongestStreak(const int steps[], int size, int goal);
```

### 📥 Input / Output Example
```text
Enter 10 daily step counts:
6500 8200 9100 10500 7400 8100 8800 9200 9500 6000

Enter daily step goal: 8000

=== FITNESS REPORT ===
- Average daily steps: 8330 steps
- Best Day: Day 3 (10500 steps)
- Longest Active Streak (>= 8000 steps): 4 consecutive days
```

```text
Enter 10 daily step counts:
5600 7800 2540 1360 4370 10340 9800 8600 4390 12090
Enter daily step goal: 9000

=== FITNESS REPORT ===
- Average daily steps: 6689 steps
- Best Day: Day 9 (12090 steps)
- Longest Active Streak (>= 9000 steps): 2 consecutive days
```
