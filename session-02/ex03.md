# Exercise 03: Complete Multi-Currency Kiosk

### 📝 Problem Statement
Write a complete C++ program that:
1. Asks the user to enter their current balance in Euros (a positive decimal number).
2. Displays the interactive conversion menu (1: USD, 2: GBP, 3: JPY).
3. Reads the user's choice and computes the converted capital using the following fixed rates:
  - $1 \text{ EUR} = 1.08 \text{ USD}$
  - $1 \text{ EUR} = 0.85 \text{ GBP}$
  - $1 \text{ EUR} = 162.5 \text{ JPY}$
4. Displays the final converted amount with appropriate currency labels.

### 📥 Input / Output Example
```text
=== Multi-Currency Kiosk ===
Enter your current balance in Euros: 100

Select target currency:
1) US Dollars (USD)
2) British Pounds (GBP)
3) Japanese Yen (JPY)
Enter choice (1-3): 3

100.00 EUR = 16250.00 JPY
```


```text
=== Multi-Currency Kiosk ===
Enter your current balance in Euros: -50.5

Error: Balance cannot be negative.
```


```text
=== Multi-Currency Kiosk ===
Enter your current balance in Euros: 250

Select target currency:
1) US Dollars (USD)
2) British Pounds (GBP)
3) Japanese Yen (JPY)
Enter choice (1-3): 4

Error: Invalid option selected.
```
