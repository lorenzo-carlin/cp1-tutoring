# Exercise 01: Simple Currency Converter (Euro to USD)

### 📝 Problem Statement
Write a C++ program that asks the user to enter a monetary amount in Euros (e.g., as a `double`). The program must calculate and display the equivalent value in US Dollars (USD).
Consider the following exchange rate: 1 EUR = 1.08 USD

### 📥 Input / Output Example
```text
Enter capital in Euros: 150.00
150.00 EUR is equivalent to 162.00 USD
```
