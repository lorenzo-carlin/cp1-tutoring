# Exercise 14: Recursive Binomial Coefficient Calculation

### 📝 Problem Statement
Write a C++ program that calculates the binomial coefficient $\binom{n}{k}$ for two input integers $n$ and $k$ such that $0 \le k \le n$.

The binomial coefficient represents the number of ways to choose $k$ elements from a set of $n$ elements and is defined as:

$$
\binom{n}{k} = \frac{n!}{k!(n-k)!}
$$

Using Pascal's identity, it can be computed recursively as:

```math
\binom{n}{k} = \begin{cases} 1 & \text{if } k = 0 \text{ or } k = n \\ \binom{n-1}{k-1} + \binom{n-1}{k} & \text{if } 0 < k < n \end{cases}
```

### 📥 Input / Output Example
```text
Enter n and k: 5 2
The binomial coefficient C(5, 2) is: 10
```

```text
Enter n and k: 6 0
The binomial coefficient C(6, 0) is: 1
```
