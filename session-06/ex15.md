# Exercise 15: Greatest Common Divisor (Euclidean Algorithm)

### 📝 Problem Statement
Write a recursive C++ function with two integer parameters $m$ and $n$ that calculates the Greatest Common Divisor (GCD) of $m$ and $n$ using the Euclidean Algorithm.

Write a C++ program that tests this function by reading two positive integers from standard input, invoking the function, and printing the computed result.

### 📐 Euclidean Algorithm Formula
The algorithm is based on the principle that the greatest common divisor of two numbers does not change if the larger number is replaced by its remainder when divided by the smaller number:
```math
\text{GCD}(m, n) = \begin{cases} m & \text{if } n = 0 \\ \text{GCD}(n, m \bmod n) & \text{if } n > 0 \end{cases}
```

### 📥 Input / Output Example
```text
Enter two positive integers (m n): 48 18
The GCD of 48 and 18 is: 6
```

```text
Enter two positive integers (m n): 101 10
The GCD of 101 and 10 is: 1
```
