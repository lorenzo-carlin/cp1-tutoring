# Exercise 04: Prime Gap Finder

### 📝 Problem Statement
Write a C++ program that prompts the user to enter a positive integer $N$. The program must determine whether $N$ is a prime number and then find the smallest prime number strictly greater than $N$ (the "next prime"), along with the numerical distance (gap) between $N$ and that next prime.You are required to break down the solution into two modular functions:
1. `bool isPrime(int val)`: Returns true if val is a prime number, false otherwise.
2. `void findNextPrime(int start, int &nextPrime, int &gap)`: Searches sequentially for the first prime number strictly greater than start. It updates both nextPrime and gap using pass-by-reference.

### 📥 Input / Output Example
```text
Enter a positive integer: 14
14 is NOT a prime number.
Next prime: 17
Gap (distance): 3
```

```text
Enter a positive integer: 13
13 is a prime number!
Next prime: 17
Gap (distance): 4
```
