# Exercise 05: Euclidean Distance Calculator

### 📝 Problem Statement
Write a C++ program that reads the coordinates of two 2D points, $P_1 = (x_1, y_1)$ and $P_2 = (x_2, y_2)$, and calculates the Euclidean distance between them.Implement a function to calculate the distance with the following prototype:
`void calculateDistance(double x1, double y1, double x2, double y2, double *distance);`
This function computes the Euclidean distance and stores the result directly in the memory location pointed to by `distance`.

Include `<cmath>` and use `std::sqrt` and `std::pow` to compute the Euclidean distance formula: $d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$

### 📥 Input / Output Example
```text
Enter Point 1 (x1 y1): 0.0 0.0
Enter Point 2 (x2 y2): 3.0 4.0

Euclidean distance between P1 and P2: 5.00
```

```text
Enter Point 1 (x1 y1): -1.5 2.0
Enter Point 2 (x2 y2): 2.5 -1.0

Euclidean distance between P1 and P2: 5.00
```
