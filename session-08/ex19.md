# Exercise 19: Run-Length String Compressor

### 📝 Problem Statement
Write a C++ program that reads a string and compresses it using **run-length encoding**. Every contiguous substring made of **two or more equal characters** must be replaced by the character itself followed by the number of times it is repeated. Characters that do not repeat must be copied unchanged.

For example, `aabbbcdddd` becomes `a2b3cd4`.

### 🛠️ Function Prototype
Implement the compression in a separate function with the following signature:

```c++
string compress(const string input);
```

### 📥 Input / Output Examples

```text
Enter a string: aabbbcdddd
Compressed string: a2b3cd4
```

```text
Enter a string: aaabbc
Compressed string: a3b2c
```

```text
Enter a string: abcd
Compressed string: abcd
```
