# Exercise 18: Title Case Formatting of a String

### 📝 Problem Statement
Write a C++ program that prompts the user to enter a sentence and then formats it so that **every word starts with an uppercase letter** and **all the remaining letters are lowercase**.

You can assume that the input contains only letters and spaces, with no special characters or digits. Words are separated by one or more spaces.

### 📥 Input / Output Examples

```text
Enter a sentence: hello WORLD from computer programming
Formatted sentence: Hello World From Computer Programming
```

```text
Enter a sentence: tHiS is A TeSt
Formatted sentence: This Is A Test
```
