# Exercise 22: Inventory Manager

### 📝 Problem Statement
A shop stores its products in a text file named `inventory.txt`. The first line contains the number of products `N`; the following `N` lines contain a product name, the available quantity and the unit price, separated by spaces:

```text
4
Penne 100 1.50
Quaderni 40 2.75
Zaino 5 39.90
Matita 0 0.80
```

Write a C++ program that loads the inventory into an array of structs and lets the user manage it through a menu:

1. **Show inventory**: print every product with its quantity and price, plus the total value of the inventory.
2. **Sell product**: ask for a product name and a quantity, and decrease the stock if it is sufficient.
3. **Restock product**: ask for a product name and a quantity, and increase the stock.
4. **Save and exit**: write the updated inventory back to the same file and terminate.

### 🛠️ Data Structure & Function Prototypes

```c++
struct Product {
    string name;
    int quantity;
    double unitPrice;
};

int loadInventory(const string& fileName, Product items[], int maxItems);
int findProduct(const Product items[], int count, const string& name);
void printInventory(const Product items[], int count);
bool sellProduct(Product items[], int count, const string& name, int quantity);
bool restockProduct(Product items[], int count, const string& name, int quantity);
bool saveInventory(const string& fileName, const Product items[], int count);
```

- `loadInventory` returns the number of products loaded, or `-1` if the file cannot be opened or its content is invalid.
- `findProduct` returns the index of the product with the given name, or `-1` if it does not exist.
- `sellProduct` and `restockProduct` return `false` (without modifying the stock) if the product does not exist or the quantity is not positive; `sellProduct` also fails if the stock is insufficient.
- `saveInventory` returns `true` if the file was written successfully.

### 📥 Input / Output Examples

#### Example 1: Show the Inventory
```text
Enter inventory file name: inventory.txt

=== INVENTORY MANAGER ===
1) Show inventory
2) Sell product
3) Restock product
4) Save and exit
Enter choice: 1

=== INVENTORY ===
1. Penne        Qty:  100  Price: 1.50 EUR
2. Quaderni     Qty:   40  Price: 2.75 EUR
3. Zaino        Qty:    5  Price: 39.90 EUR
4. Matita       Qty:    0  Price: 0.80 EUR
Total inventory value: 459.50 EUR
```

#### Example 2: Sell a Product and Save
```text
Enter inventory file name: inventory.txt

=== INVENTORY MANAGER ===
1) Show inventory
2) Sell product
3) Restock product
4) Save and exit
Enter choice: 2
Enter product name: Penne
Enter quantity to sell: 10

Sold 10 x Penne. New stock: 90

=== INVENTORY MANAGER ===
1) Show inventory
2) Sell product
3) Restock product
4) Save and exit
Enter choice: 4

Inventory saved to inventory.txt. Goodbye!
```

After saving, `inventory.txt` becomes:

```text
4
Penne 90 1.50
Quaderni 40 2.75
Zaino 5 39.90
Matita 0 0.80
```

#### Example 3: Insufficient Stock
```text
Enter choice: 2
Enter product name: Zaino
Enter quantity to sell: 8

Error: insufficient stock for Zaino (available: 5).
```

#### Example 4: Unknown Product
```text
Enter choice: 2
Enter product name: Carta
Enter quantity to sell: 1

Error: product "Carta" not found.
```

#### Example 5: Invalid Menu Choice
```text
Enter choice: 7
Error: invalid choice. Please enter a number between 1 and 4.
```
