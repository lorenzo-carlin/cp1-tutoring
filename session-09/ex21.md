# Exercise 21: Student Records Report

### 📝 Problem Statement
A file named `students.txt` stores the exam results of a group of students. The first line contains the number of students `N`; the following `N` lines contain a first name, a last name and three integer grades, separated by spaces:

```text
5
Mario Rossi 8 9 7
Luca Bianchi 4 5 6
Giulia Verdi 10 9 10
Anna Neri 6 6 6
Paolo Blu 3 4 5
```

Write a C++ program that loads the records into an array of structs and prints a report containing:

1. each student's grades and average (with 2 decimal digits);
2. the average grade of the whole class;
3. the best student, i.e. the one with the highest average (in case of a tie, the first one in file order);
4. the number of passed and failed students, considering a student passed if their average is at least 6.

The report must be shown on the screen **and** saved to a file named `report.txt`.

### 🛠️ Data Structure & Function Prototypes

```c++
struct Student {
    string firstName;
    string lastName;
    int grades[3];
    double average;
};

int loadStudents(const string& fileName, Student students[], int maxStudents);
double computeAverage(const Student& student);
void writeReport(const Student students[], int count, ostream& out);
bool saveReport(const string& fileName, const Student students[], int count);
```

- `loadStudents` returns the number of students loaded, or `-1` if the file cannot be opened or its content is invalid.
- `writeReport` writes the report to the given output stream, so the same function can be reused both for `cout` and for an `ofstream`.
- `saveReport` returns `true` if the file was written successfully.

### 📥 Input / Output Examples

```text
Enter students file name: students.txt

=== STUDENT REPORT ===
Mario Rossi: 8.00 9.00 7.00 -> Average: 8.00
Luca Bianchi: 4.00 5.00 6.00 -> Average: 5.00
Giulia Verdi: 10.00 9.00 10.00 -> Average: 9.67
Anna Neri: 6.00 6.00 6.00 -> Average: 6.00
Paolo Blu: 3.00 4.00 5.00 -> Average: 4.00

Class average: 6.53
Best student: Giulia Verdi (9.67)
Passed: 3 | Failed: 2

Report written to report.txt.
```

The file `report.txt` must contain exactly the same report, without the final confirmation line:

```text
=== STUDENT REPORT ===
Mario Rossi: 8.00 9.00 7.00 -> Average: 8.00
Luca Bianchi: 4.00 5.00 6.00 -> Average: 5.00
Giulia Verdi: 10.00 9.00 10.00 -> Average: 9.67
Anna Neri: 6.00 6.00 6.00 -> Average: 6.00
Paolo Blu: 3.00 4.00 5.00 -> Average: 4.00

Class average: 6.53
Best student: Giulia Verdi (9.67)
Passed: 3 | Failed: 2
```

