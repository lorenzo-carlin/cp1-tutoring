# Exercise 20: Text File Analyzer

### 📝 Problem Statement
Write a C++ program that asks the user for the name of a text file and produces a statistics report about its content. The program must read the file **line by line** and compute:

1. the total number of lines;
2. the number of empty lines (lines with length 0);
3. the total number of words (a word is a sequence of non-space characters);
4. the total number of characters, excluding newline characters;
5. the longest line and its 1-based line number (in case of a tie, keep the first one).

All the statistics must be stored in the following struct:

```c++
struct FileStats {
    int totalLines;
    int emptyLines;
    int words;
    int characters;
    string longestLine;
    int longestLineNumber;
};
```

### 🛠️ Function Prototype
Implement the analysis in a separate function with the following signature:

```c++
bool analyzeFile(const string& fileName, FileStats& stats);
```

The function returns `false` if the file cannot be opened, and `true` otherwise. Before returning, it must fill every field of `stats`.

### 📥 Input / Output Examples

Suppose `sample.txt` contains:

```text
C++ makes file handling fun
Structs group related data

Practice every day
```

```text
Enter file name: sample.txt

=== FILE REPORT ===
Total lines: 4
Empty lines: 1
Total words: 12
Total characters: 71
Longest line: #1 (27 characters)
> C++ makes file handling fun
```

```text
Enter file name: notes.txt
Error: could not open file "notes.txt".
```
