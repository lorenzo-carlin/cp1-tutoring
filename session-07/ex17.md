# Exercise 17: Anagram Detector via Character Array Sorting

### 📝 Problem Statement
Write a modular C++ program that prompts the user to input two character arrays of equal length $N$. The program must determine whether the two words are **anagrams** of each other by sorting both character arrays in ascending alphabetical order and checking if they become identical.

### 🛠️ Function Prototypes
Implement the core logic using the following functions:

```c++
void sortCharArray(char arr[], int size);
bool areAnagrams(const char arr1[], const char arr2[], int size);
```

### ⚡ Requirements & Constraints

1. **Sorting Function**: `sortCharArray` must sort an array of `char` in ascending alphabetical order using any of the sorting algorithms covered in class (Selection, Insertion, or Bubble Sort).
2. **Anagram Check**: `areAnagrams` must make local working copies of `arr1` and `arr2`, sort both copies using `sortCharArray`, and perform a linear scan to verify if all characters at each index match. It returns `true` if the words are anagrams, and `false` otherwise.
3. Do **not** use `std::string` operations or `<algorithm>` functions like `std::sort`.

### 📥 Input / Output Examples

#### Example 1: Valid Anagrams
```text
Enter array length N: 4
Enter characters for Array 1: n o t e
Enter characters for Array 2: t o n e

Sorted Array 1: e n o t
Sorted Array 2: e n o t

Result: The input sequences are ANAGRAMS!
```

#### Example 2: Invalid Anagrams
```text
Enter array length N: 5
Enter characters for Array 1: a p p l e
Enter characters for Array 2: p a p e s

Sorted Array 1: a e l p p
Sorted Array 2: a e p p s

Result: The input sequences are NOT anagrams.
```
