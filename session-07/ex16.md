# Exercise 16: Sorting Algorithms Benchmark via Command-Line Arguments (`argc`, `argv`)

### 📝 Problem Statement
Write a modular C++ program that receives a sequence of integer values directly from the command line (`argc`, `argv`), populates an array, and benchmarks three classic sorting algorithms: **Selection Sort**, **Insertion Sort**, and **Bubble Sort**.

The program must calculate and display the total number of element **swaps** performed by each algorithm to sort the exact same input sequence.

### 🛠️ Function Prototypes
Implement the three sorting algorithms using the following signatures, where each function **returns the number of swaps performed as an `int`**:

```c++
int selectionSort(int arr[], int size);
int insertionSort(int arr[], int size);
int bubbleSort(int arr[], int size);
```

### ⚡ Requirements & Constraints

1. **Argument Parsing**: Check that at least one integer argument is provided (`argc > 1`). If no values are passed, display a syntax usage error message (e.g., `Usage: ./a.out <n1> <n2> ...`) and exit with status `1`.
2. **Array Population**: Parse arguments `argv[1]` through `argv[argc - 1]` using `std::atoi` into an integer array of size $N = \text{argc} - 1$.
3. **Data Preservation**: Since sorting algorithms modify arrays *in-place*, create three identical copies of the original array so that each sorting function operates on the same unsorted sequence.

### 📥 Input / Output Examples

#### Example 1: General Array
```bash
$ ./a.out 5 2 8 1 4

Received 5 input elements.
Original Array: [ 5, 2, 8, 1, 4 ]

=== BENCHMARK RESULTS ===
Sorted Array:   [ 1, 2, 4, 5, 8 ]

- Selection Sort: 2 swaps
- Insertion Sort: 6 swaps
- Bubble Sort:    6 swaps
```

#### Example 2: Reverse Sorted Array (Worst Case)
```bash
$ ./a.out 5 4 3 2 1

Received 5 input elements.
Original Array: [ 5, 4, 3, 2, 1 ]

=== BENCHMARK RESULTS ===
Sorted Array:   [ 1, 2, 3, 4, 5 ]

- Selection Sort: 2 swaps
- Insertion Sort: 10 swaps
- Bubble Sort:    10 swaps
```
