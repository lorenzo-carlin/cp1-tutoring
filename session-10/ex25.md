# Exercise 25: Sliding Window Sensor Monitor

### 📝 Problem Statement
A text file named `readings.txt` contains a sequence of integer sensor readings separated by spaces or newlines:

```text
2 4 9 13 20
```

Write a C++ program that asks the user for the file name, the window size `K` and an alert threshold `T`, then processes the readings one by one. The last `K` readings must be kept in a **singly linked list used as a FIFO queue**:

- every new reading is appended after `tail`, with its 1-based position in the stream;
- if the queue already contains `K` readings, the node at `head` is removed before the new one is appended;
- when the window is full (`size == K`), compute `span = newest.value - oldest.value`; if `abs(span) >= T`, print an alert with the reading index, the oldest and newest values and the signed span.

At the end, print the final window in chronological order (oldest first). Assume the file contains only integers; if it cannot be opened, the program prints an error and exits.

### 🛠️ Data Structure & Function Prototypes

```c++
struct ReadingNode {
    int value;
    int index;      // 1-based position in the stream
    ReadingNode* next;
};

struct Window {
    ReadingNode* head;
    ReadingNode* tail;
    int size;
};

void initWindow(Window& window);
void pushReading(Window& window, int value, int index, int capacity);
int windowSpan(const Window& window);   // newest.value - oldest.value
void printWindow(const Window& window);
void destroyWindow(Window& window);
bool monitorFile(const string& fileName, int capacity, int threshold);
```

- `initWindow` sets `head` and `tail` to `nullptr` and `size` to 0.
- `pushReading` appends the new node, evicts the oldest one when the window would exceed `capacity`, and keeps `head`, `tail` and `size` consistent (including when the queue has 0 or 1 elements).
- `windowSpan` returns `0` for an empty window.
- `monitorFile` opens the file, reads the integers with `>>`, prints a line for each full window and returns `false` if the file cannot be opened.

### 📥 Input / Output Examples

#### Example 1: Positive spike
```text
Enter file name: readings.txt
Enter window size K: 3
Enter alert threshold: 10

Reading #3 (9):  window [2, 4, 9],   span +7
Reading #4 (13): window [4, 9, 13],  span +9
Reading #5 (20): window [9, 13, 20], span +11 -> ALERT at #5: oldest 9, newest 20, span +11

Final window (3 readings): 9 13 20
```

#### Example 2: Negative drops
```text
Enter file name: readings.txt
Enter window size K: 3
Enter alert threshold: 10

Reading #3 (8): window [20, 15, 8], span -12 -> ALERT at #3: oldest 20, newest 8, span -12
Reading #4 (5): window [15, 8, 5],  span -10 -> ALERT at #4: oldest 15, newest 5, span -10

Final window (3 readings): 15 8 5
```

#### Example 3: File not found
```text
Enter file name: missing.txt
Enter window size K: 3
Enter alert threshold: 10

Error: could not open file "missing.txt".
```
