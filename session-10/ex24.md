# Exercise 24: Run-Length Zip / Unzip

### 📝 Problem Statement
Write a C++ program that reads a string from the user and stores it in a singly linked list where each node holds one character and `count = 1`. The program must then perform two operations **in place**:

1. **Compress**: every maximal run of equal consecutive characters becomes a single node whose `count` is the length of the run. Reuse the first node of the run and `delete` all the other nodes of that run. For example, `aaabbc` becomes `a(3)b(2)c(1)` and the list shrinks from 6 nodes to 3.
2. **Expand**: turn the compact list back into one node per character, always with `count = 1`. Reuse each compact node for the first character of its run and allocate new nodes for the remaining ones. `a(3)b(2)c(1)` becomes `a a a b b c` again.

After each step, print the compact representation, the reconstructed text and the number of nodes, so that the in-place reuse is visible.

### 🛠️ Data Structure & Function Prototypes

```c++
struct RunNode {
    char value;
    int count;
    RunNode* next;
};

RunNode* buildList(const string& text);   // one node per character, count = 1
void compress(RunNode*& head);            // merge consecutive equal values, summing their counts
void expand(RunNode*& head);              // split each run into count nodes with count = 1
void printCompact(const RunNode* head);   // e.g. a(3)b(2)c(1)
void printText(const RunNode* head);      // e.g. aaabbc
int nodeCount(const RunNode* head);
void destroyList(RunNode*& head);
```

- `compress` merges consecutive nodes with the same `value` by summing their `count` fields. Applying it twice to the same list must not change it.
- `expand` replaces a node with `count = k` by a run of `k` nodes with `count = 1`: keep the original node for the first character and insert `k - 1` new nodes after it.
- `printText` must work both on a compact list and on an expanded one: it prints each node's `value` repeated `count` times.

### 📥 Input / Output Examples

#### Example 1: Long runs
```text
Enter text: aaabbc

Original text: aaabbc (6 nodes)
Compact list:  a(3)b(2)c(1) (3 nodes)
Expanded text: aaabbc (6 nodes)
```

#### Example 2: No consecutive repeats
```text
Enter text: abcabc

Original text: abcabc (6 nodes)
Compact list:  a(1)b(1)c(1)a(1)b(1)c(1) (6 nodes)
Expanded text: abcabc (6 nodes)
```

#### Example 3: A single run
```text
Enter text: AAAAA

Original text: AAAAA (5 nodes)
Compact list:  A(5) (1 node)
Expanded text: AAAAA (5 nodes)
```

#### Example 4: Empty string
```text
Enter text: 

Original text:  (0 nodes)
Compact list:  (0 nodes)
Expanded text:  (0 nodes)
```
