# Exercise 23: Cursor Text Editor

### 📝 Problem Statement
Write a C++ program that manages a single line of text as a **singly linked list of characters**. A cursor marks the insertion point: the next character typed appears exactly where the `|` marker is shown. The cursor is stored as a `CharNode*` pointing to the node **immediately before** the insertion point; a dummy (sentinel) head node is used so that inserting at the beginning is no different from inserting anywhere else.

The program offers a menu:

1. **Move cursor left**
2. **Move cursor right**
3. **Insert character**
4. **Backspace** — delete the character before the cursor
5. **Delete character** — delete the character after the cursor
6. **Print line**
7. **Quit**

Only single characters (no spaces) can be inserted; read them with `cin >> c`. When quitting, every allocated node — including the sentinel — must be released.

### 🛠️ Data Structure & Function Prototypes

```c++
struct CharNode {
    char value;
    CharNode* next;
};

void initLine(CharNode*& head, CharNode*& cursor);
bool moveLeft(CharNode* head, CharNode*& cursor);
bool moveRight(CharNode*& cursor);
void insertChar(CharNode*& head, CharNode*& cursor, char c);
bool backspace(CharNode*& head, CharNode*& cursor);
bool deleteChar(CharNode*& cursor);
void printLine(const CharNode* head, const CharNode* cursor);
void destroyLine(CharNode*& head);
```

- `initLine` creates the sentinel node and sets the cursor to it; the line starts empty.
- `moveLeft` returns `false` if the cursor is already at the beginning; otherwise it scans from `head` to find the node before the cursor.
- `moveRight` returns `false` if there is no node after the cursor.
- `insertChar` allocates a new node after the cursor and leaves the cursor after the new node.
- `backspace` removes the node the cursor points to (that is the character before the insertion point) and moves the cursor to its predecessor; it returns `false` at the beginning of the line.
- `deleteChar` removes the node after the cursor without moving the cursor; it returns `false` at the end of the line.
- `printLine` prints the text with a `|` at the insertion point, e.g. `He|llo`.

### 📥 Input / Output Examples

#### Example 1: Editing a line
```text
=== CURSOR EDITOR ===
1) Move cursor left
2) Move cursor right
3) Insert character
4) Backspace
5) Delete character
6) Print line
7) Quit
> 3
Character: H
Text: H|
> 3
Character: i
Text: Hi|
> 1
Text: H|i
> 3
Character: !
Text: H!|i
> 4
Text: H|i
> 5
Text: H|
> 7
Bye!
```

#### Example 2: Impossible operations
```text
> 1
Error: cursor is already at the beginning.
Text: |
> 5
Error: no character after the cursor.
Text: |
```
