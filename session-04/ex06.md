# Exercise 06: Dice Target Simulator

### 📝 Problem Statement
Write a C++ program that prompts the user to enter a target score $T$ ($T \ge 10$). The program simulates rolling three 6-sided dice simultaneously in a loop using pseudo-random number generation.
The simulation continues rolling all three dice until the cumulative sum of all rolls reaches or exceeds the target score $T$.

Implement the simulation logic in a procedure with the following prototype:
`void simulateTargetRolls(int target, int &totalRolls, int &finalScore);`

### 📥 Input / Output Example
```text
Enter target score (>= 10): 35

Simulating dice rolls...
Target 35 reached!
- Total three-dice rolls required: 4
- Final cumulative score: 38
```

```text
Enter target score (>= 10): 5

Error: Target score must be at least 10.
```

### ⚡ Additional Requirement
1. **Constraint**: Do not use arrays, vectors, or complex data structures.
2. Seed the random number generator once in `main` using `std::srand(std::time(nullptr))` from `<cstdlib>` and `<ctime>`.
3. The procedure `simulateTargetRolls` must return the total number of rolls and the final score to `main` using reference parameters (`&`).
