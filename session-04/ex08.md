# Exercise 08: Armstrong Numbers Finders (k-digits)

### 📝 Problem Statement
Write a C++ program that prompts the user to enter a number of digits $k$ within the range $3 \le k \le 7$. The program must search for and display all $k$-digit Armstrong numbers (also known as narcissistic numbers). An Armstrong number of $k$ digits is a positive integer that is equal to the sum of its own digits each raised to the power of $k$.

For example, for $k = 3$, $153$ is an Armstrong number because: $$1^3 + 5^3 + 3^3 = 1 + 125 + 27 = 153$$

Implement a modular function to verify each number with the following prototype:
`bool isArmstrong(int number, int k);`

The function extracts each digit of `number`, computes the sum of those digits raised to the $k$-th power and stores it in a variable called `sumOfPowers`, and returns `true` if `number == sumOfPowers`, or `false` otherwise.

### 📥 Input / Output Example

```text
Enter number of digits k (3-7): 3

Searching for 3-digit Armstrong numbers...
- Found: 153
- Found: 370
- Found: 371
- Found: 407

Total 3-digit Armstrong numbers found: 4
```

```text
Enter number of digits k (3-7): 4

Searching for 4-digit Armstrong numbers...
- Found: 1634
- Found: 8208
- Found: 9474

Total 4-digit Armstrong numbers found: 3
```

```text
Enter number of digits k (3-7): 8

Error: k must be an integer between 3 and 7.
```

### ⚡ Additional Requirement
1. Constraint: Do not use arrays, vectors, or strings.
2. Include `<cmath>` and use `std::pow` to compute the $k$-th power of each digit.
3. Validate input in `main`: if the user enters $k < 3$ or $k > 7$, print an error message and terminate the program.
