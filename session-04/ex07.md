# Exercise 07: Perfect Number Checker

### 📝 Problem Statement
Write a C++ program that prompts the user to enter a positive integer $N$. A positive integer is called a perfect number if it is equal to the sum of its positive proper divisors (excluding the number $N$ itself). For example, $6$ is a perfect number because its proper divisors are $1, 2,$ and $3$, and $1 + 2 + 3 = 6$.

Implement a modular function to compute the divisor sum and check for perfection with the following prototype:
`bool isPerfectNumber(int number, int &sumDivisors);`

The function computes the sum of all proper divisors of `number`, stores the calculated sum into the reference parameter `sumDivisors`, and returns `true` if `number` is perfect, or `false` otherwise.

### 📥 Input / Output Example
```text
Enter a positive integer: 6

Divisor analysis:
- Sum of proper divisors: 6
Result: 6 IS a perfect number!
```

```text
Enter a positive integer: 28

Divisor analysis:
- Sum of proper divisors: 28
Result: 28 IS a perfect number!
```

```text
Enter a positive integer: 12

Divisor analysis:
- Sum of proper divisors: 16
Result: 12 is NOT a perfect number.
```

### ⚡ Additional Requirement
1. **Constraint**: Do not use arrays, vectors, or strings.
2. The function `isPerfectNumber` must return the calculated sum of proper divisors to `main` using a pass-by-reference parameter (`&`).
3. Validate user input in `main`: if the user enters $N \le 0$, display an error message and ask again or terminate gracefully.
